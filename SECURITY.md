# Security Policy

This repository is a starter learning template with fictional sample data only.

- Do not commit real software names, vendor account names, licence keys, or credentials. The template CSV contains made-up examples.
- Do not commit credentials or API keys. Keep those in your organisation's own secure store, never in a repo.
- Real licence details are sensitive. This repo contains no real figures — only fictional sample rows.
- If you find a security issue in the template itself, please open an issue describing it (without real company data).
